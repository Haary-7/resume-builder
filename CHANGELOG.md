# Changelog

## 1.0.0 — initial public release

- Local-first editor with eight single-column templates and native PDF export.
- Responsive workspace, collapsible sections, focus preview and word count.
- Undo/redo, named versions, and JSON/Markdown backup/export.
- Heuristic resume checks and basic job-keyword comparison.
- Optional local OpenCode integration and direct provider review modes.
- Cross-platform setup-guide bootstrap and installable `resume-builder` command.
- Managed start/stop, static builds, ZIP distribution, Docker and Kubernetes support.
- Public builds with a blank seed; fictional sample data for tests and screenshots.
- Documentation, MIT license, CI and manual GitHub Pages deployment workflow.
